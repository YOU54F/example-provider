

## Installing Luarocks

See the [installation guide](https://github.com/luarocks/luarocks/blob/main/docs/download.md) on LuaRocks github repo

MacOS

`brew install lua luajit luarocks`

Windows

`choco install lua luarocks`

`scoop install lua luarocks`

Ubuntu / Debian

`sudo apt install luarocks`

Alpine

`apk add luarocks`

RHEL

`dnf module install luarocks`
